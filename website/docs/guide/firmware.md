# Firmware

## Download

The firmware code can be found [here](https://github.com/AndrewCromar/stepminia/tree/main/firmware) (repo/firmware). Or you can download the pre-compiled `.uf2` file [here](https://github.com/AndrewCromar/stepminia/blob/main/firmware/stepminia.uf2).

## Upload

1. Plug the pcb into your computer while holding the `bootsel` button.
2. Drag the uf2 file to the Stepminia device.

It will restart and have the firmware fully installed. It will act as a keyboard.

## Test

You can test the device by pressing any of the buttons or bridging the contact pads (aluminum foil works good). [This site is good for viewing inputs.](https://keyboard-tester.com/)
